# Brand assets

- `logo/` — the approved logo (navy ring + azure `<`), live as `public/icon.svg` and the desktop icons. Regenerate: `node logo/logo-gen.mjs`; desktop PNG/ICO: `node packages/desktop/scripts/icon-raster.mjs`. `icon.icns` needs macOS (`packages/desktop/scripts/icon.mjs`).

The Onni mascot is a design/demo only and lives in `docs/design/mascot/`.
