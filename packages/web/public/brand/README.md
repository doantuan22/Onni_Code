# Brand proposals (not wired into the app yet)

Pixel-art, rect-only SVGs generated from grids; regenerate with `node logo/logo-gen.mjs` and `node mascot/mascot-gen.mjs`.

- `logo/` — new mark (navy ring + azure `<` chevron), `onni-mark-dark.svg` for navy surfaces, mono, 16px, canonical rect lockup. Review + resolution in `logo/REVIEW.md`.
- `mascot/` — "Onni", a pixel robot-fox: idle/working/success/error/sleep, 16px head, `sprite-frames.json` with timings, `playback-preview.html`. Review + resolution in `mascot/REVIEW.md`.

The owner-approved logo is adopted as `public/icon.svg`; the desktop icon sources use the same mark.
